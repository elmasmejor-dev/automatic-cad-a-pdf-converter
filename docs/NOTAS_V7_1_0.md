# Automatic CAD a PDF Converter v7.1.0

## Novedades

- Consulta automática de actualizaciones a GitHub Releases cada vez que se abre el programa, sin bloquear la interfaz.
- Ventana para leer las novedades y elegir **Descargar e instalar**, **Más tarde** o **Ver en GitHub**.
- Botón **Buscar actualizaciones** para ejecutar una comprobación manual.
- Descarga del instalador desde el repositorio oficial con verificación SHA-256 antes de ejecutarlo.
- Reutilización de Python y bibliotecas ya instaladas en una actualización, para acelerar el asistente.

## Se mantienen

- Visor clásico y mapa de láminas a pantalla completa.
- Miniaturas y selección múltiple de hojas.
- Papeles A0–A4 automáticos y manuales.
- Conversión PDF individual o conjunta, motor AutoCAD y modo silencioso.

**Instalador:** `Setup_Automatic_CAD_a_PDF_Converter_v7_1_0.exe`
